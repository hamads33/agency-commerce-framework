# Feature Matrix

| Area | Agency Commerce v1.0 |
| --- | --- |
| Parent theme | Classic WordPress theme with `wp-content/themes/agency-commerce/theme.json` tokens |
| Companion plugin | Settings, presets, blocks, product extensions, checkout controls |
| Child themes | Supported workflow for client/store presentation |
| Showcase themes | Fashion, Electronics, Home |
| Homepage | Gutenberg content plus Agency Commerce blocks and patterns |
| Shop | WooCommerce archive shell, filter sidebar/drawer, product-card variants |
| Product cards | Classic, minimal, compact |
| Product pages | Standard and sticky summary layouts |
| Cart | WooCommerce block cart styling and mini-cart block fallback |
| Checkout | WooCommerce block checkout styling, classic fallback toggle |
| My Account | Styled native WooCommerce endpoints |
| Presets | Minimal, Fashion, Electronics |
| REST | Recently viewed render endpoint only |
| Packaging | Parent theme, plugin, and starter child ZIPs |
| Testing | PHP lint, PHPCS, JS lint, Playwright smoke and visual suites |
| Not included | Gateways, shipping rates, tax logic, subscriptions, marketplace, ERP, faceted search |
