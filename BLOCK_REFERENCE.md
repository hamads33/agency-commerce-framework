# Block Reference

Agency Commerce custom blocks are presentation blocks. Product querying remains
delegated to WooCommerce product blocks wherever possible.

## Blocks

| Block | Name | Purpose |
| --- | --- | --- |
| Hero | `agency-commerce/hero` | Storefront hero section |
| Category Grid | `agency-commerce/category-grid` | Product category presentation |
| Promo Banner | `agency-commerce/promo-banner` | Campaign banner |
| Image and Text | `agency-commerce/image-text` | Editorial content section |
| Trust Bar | `agency-commerce/trust-bar` | Service promises |
| Testimonials | `agency-commerce/testimonials` | Social-proof section |
| Brand Logos | `agency-commerce/brand-logos` | Logo-list presentation |
| FAQ | `agency-commerce/faq` | Question/answer section |
| Newsletter | `agency-commerce/newsletter` | Newsletter CTA wrapper |
| Recently Viewed Products | `agency-commerce/recently-viewed-products` | Local-storage recently viewed render placeholder |

## Patterns

- `agency-commerce/fashion-homepage`
- `agency-commerce/electronics-homepage`
- `agency-commerce/minimal-homepage`

Patterns insert editable content only. They do not overwrite pages or products.
