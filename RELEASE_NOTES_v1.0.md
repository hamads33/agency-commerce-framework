# Agency Commerce v1.0 Release Notes

Agency Commerce v1.0 is a release-candidate-ready WooCommerce framework for
agency-built storefronts.

## Included Packages

- Parent theme: `agency-commerce`
- Companion plugin: `agency-commerce-core`
- Starter child theme: `agency-commerce-child`
- Showcase child themes: Fashion, Electronics, Home

## Major Capabilities

- Token-driven premium design system.
- Settings-backed header, shop, product, cart, checkout, footer, and social
  controls.
- WooCommerce block cart and checkout styling.
- Classic checkout fallback.
- Homepage presentation blocks and patterns.
- Product badges, delivery messaging, WhatsApp enquiry, and recently viewed
  rendering.
- Production packaging scripts and visual regression coverage.
