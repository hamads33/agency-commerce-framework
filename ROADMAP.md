# Roadmap

Agency Commerce v1.0 is feature complete for the current release. Future work
should be evaluated as separate product cycles.

## Near-Term Maintenance

- Monitor WordPress and WooCommerce compatibility.
- Revisit accepted development-tool audit risks when `@wordpress/scripts`
  updates safely.
- Expand browser/device visual coverage when project needs justify it.
- Add more case-study content from real client launches.

## Possible Future Product Work

- Additional showcase child themes.
- More admin preview thumbnails.
- Optional importable demo content packages.
- More documented integration recipes for common WooCommerce extensions.

## Out Of Scope For v1.0

- Payment gateways.
- Shipping-rate engines.
- Tax engines.
- Marketplace/multivendor functionality.
- Subscriptions.
- ERP/POS integration.
- Custom faceted-search engine.
