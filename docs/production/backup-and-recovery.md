# Backup and recovery

Capture WordPress data, uploads and environment configuration. Keep credentials outside shared archives and logs. Retain dated copies off-host and verify their integrity. Rehearse restoration to a disposable host with payments, outgoing mail and external integrations disabled.

The backend gate captures its own pre-fixture SQL and logs under its printed artifact directory. These are disposable test snapshots. Apply them only to the matching isolated database. Recover checkout layout through its saved WordPress page metadata or an audited database restore.
