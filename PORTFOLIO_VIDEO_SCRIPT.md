# Portfolio Video Script

Target length: 2-3 minutes.

## 0:00-0:20 Opening

Agency Commerce is a reusable WooCommerce framework for agencies. One parent
theme and one companion plugin power multiple custom storefronts through child
themes, presets, and design tokens.

## 0:20-0:45 Architecture

Show the repository structure: parent theme, companion plugin, starter child
theme, and showcase child themes. Explain that commerce behavior stays in
WooCommerce and the plugin, while storefront presentation belongs in child
themes.

## 0:45-1:10 Admin Settings

Open the Commerce Framework admin screen. Walk through store identity, header,
shop, product, cart, checkout, footer, social, performance, and developer
sections. Emphasize that presets write configuration only and do not delete
content.

## 1:10-1:35 Store Switching

Switch between Fashion, Electronics, and Home showcase child themes. Explain
that each visual language changes through child-theme presentation and defaults,
not by forking the framework.

## 1:35-1:55 Responsive Behavior

Show desktop, tablet, and mobile screenshots. Point out large editorial
compositions on desktop, stacked sections on tablet, and single-column mobile
flows with visible focus and tap targets.

## 1:55-2:15 Checkout

Open cart and checkout. Explain that Agency Commerce styles WooCommerce block
cart and checkout while preserving WooCommerce payment, shipping, coupon,
validation, and order logic.

## 2:15-2:40 Developer Workflow

Show build, lint, visual regression, showcase screenshots, and packaging
commands. Mention `npm run package`, `npm run test:showcase`, and child-theme
component overrides.

## 2:40-3:00 Close

Agency Commerce gives agencies a reusable foundation, commercial-quality
storefront presentation, and documented ownership without locking stores into a
page builder.
